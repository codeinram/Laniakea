# Laniakea is a continuation on Q17
Laniakea keep the core of feed forward error correction while adding state of the art audio engineering design. Design combine the best from power lateral MOS with vertical MOS while using depletion MOS as regulators and small signal.
What has been added and changed:
Operational is now ADA4610-1.
