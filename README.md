# Laniakea is a continuation on Q17
The aim is to offer a highly musically design using available parts.
Laniakea keep the core of feed forward error correction while adding state of the art audio engineering design. Design combine the best from power lateral MOS with vertical MOS while using depletion MOS as regulators and small signal.
What has been added and changed:
Operational changed to ADA4610-1.
UF3N170400B7S together with DN2540 form a particular cascode. UF3N170400B7S is a JFET with low Vth<-9V and run DN2540 in a linear region, at a decent Vds.
Output stage is a mix of lateral and vertical mosfet, combining the linearity of laterals with high transconductance of verticals.
